\section{Progress Summary}
The M1 pipeline runs end to end on real Wikimedia Commons data: crawl through the MediaWiki API
$\rightarrow$ clean categories $\rightarrow$ temporal split $\rightarrow$ frozen CLIP ViT-B/32 encoder
$\rightarrow$ four scorers $\rightarrow$ calibrated fusion $\rightarrow$ hierarchy decoding $\rightarrow$
explained suggestions in a web demo. We ran three successively larger experiments (up to 6,303 files and
24,486 categories), fixed a validation flaw they exposed, and tested the demo on our own photos, which led
to four usability fixes. Two M1 components are still pending: graph-smoothed prototypes and conformal sets.

\vspace{2pt}
\textbf{Added beyond M1.} (1) \emph{Realistic validation:} the vocabulary is built only from data that precedes
the validation period; before, every validation label was ``known'' and fusion was tuned on an easy set.
(2) \emph{Content type first:} each result starts with Object / Scene / Event / Abstract concept, blending a
vote of the suggested categories with a zero-shot check. (3) \emph{Bias audit:} region-balanced seeds
(8 countries per continent), optional uniformly random files, accuracy per region and topic.
(4) \emph{Demo fixes from our own testing} (Section~5). (5) \emph{Tester problem reports} stored with what the
system showed, for an open feedback loop.

\section{Findings}
\begin{itemize}
\item \textbf{Realistic validation fixed model selection:} the val--test gap fell from .135 to .014, and the
tuned hierarchy rule (strength chosen on validation) no longer costs accuracy.
\item \textbf{More data improves the top of the list:} P@1 .284$\rightarrow$.350, R@10 .238$\rightarrow$.330.
F1@5 is flat on Run 3's harder test set, whose region-balanced seeds add place-specific categories.
\item \textbf{The tail is the bottleneck}, as M1 predicted: recall@5 is .830 for categories with $\geq$20
examples but .004 for unseen ones, which hold 72\% of test labels. This is exactly what graph-smoothed
prototypes target.
\item \textbf{Fusion} beats the best single scorer by 53\%; \textbf{metadata} is essential for places
(Africa .204 vs .009 image only); under heavy blur F1@5 drops 4\% with metadata vs 36\% image only.
\item \textbf{Zero-shot name matching alone collapses} over 24k names (.005), motivating smoothed prototypes and
SigLIP. Regional accuracy varies widely; groups are small, so differences are indicative.
\end{itemize}

\section{Progress on Testing}
\begin{itemize}
\item \textbf{Evaluation harness} implements every M1 metric (P/R/F1@$k$, mAP, hierarchy-aware precision,
frequency buckets, type, resolution, degradations, latency, memory, ablations) plus the region audit and
content-type accuracy.
\item \textbf{67 automated tests}, including an offline end-to-end run (train $\rightarrow$ evaluate
$\rightarrow$ predict $\rightarrow$ update) and encoder API checks on tiny CLIP and SigLIP models.
\item \textbf{Hands-on testing with our own photos} found and fixed: people pulled towards ``Marathons'' and
floor tiles towards ``Textiles'' (centre-weighted image embedding); a cathedral typed as Object (buildings and
landmarks now count as Scene); bare country names as noise (hidden); abstention applied to the wrong score
(now based on content-type confidence, threshold 50\%).
\item \textbf{Continual learning verified:} new categories and accepted feedback are suggested immediately
without retraining.
\end{itemize}

\section{Plan for the Remaining Time}
\begin{enumerate}
\item \textbf{Graph-smoothed prototypes} (M1's core idea): blend each category's text embedding with its image
centroid and its parent/sibling prototypes; ablate tail recall with and without.
\item \textbf{Conformal suggestion sets:} split conformal calibration on validation; report coverage vs target,
set size and abstention rate against fixed top-$k$.
\item \textbf{Encoder comparison} (SigLIP vs CLIP) and an \textbf{unbiased test set} of the newest Commons uploads.
\item \textbf{Reviewed score} on a sample of ``wrong'' suggestions; final report, slides and demo video.
\end{enumerate}
